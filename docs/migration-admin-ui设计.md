# migration-admin-ui 模块设计

### 6.1 模块职责

提供Web管理界面，负责：
- 迁移任务可视化配置
- 灰度规则可视化配置
- Diff结果查询与统计
- 实时监控

### 6.2 技术选型

| 技术 | 说明 |
|------|------|
| Vue 3 + TypeScript | 主流前端框架 |
| Element Plus | UI组件库 |
| Pinia | 状态管理 |
| Vue Router | 路由管理 |
| Axios | HTTP客户端 |
| ECharts | 图表统计 |
| vue-json-pretty | JSON预览组件 |

- **差异类型分布**: ECharts柱状图，MODIFY/ADD/REMOVE分布
- **响应时间对比**: ECharts折线图，对比旧接口和新接口的响应时间
- **最近记录表**: 展示该迁移任务的最新Diff记录

**API调用**：
- 选择迁移任务后，调用 `/api/v1/diff_record/statistics` 获取统计数据
- 调用 `/api/v1/diff_record/list` 获取最近记录
